# Inventory Scanner

## プロジェクト概要

`inventory-scanner` は、バーコードを使って図書や物品の棚卸しを行うための軽量な Web アプリです。ブラウザ上で動作し、カメラを使ってバーコードを読み取り、棚ごとの在庫状態を端末に保存・管理します。

## 主な機能

- カメラでバーコードを読み取り、スキャン結果を一覧表示
- 棚ごとのスキャン作業を分けて管理
- 棚卸し結果を CSV 形式でダウンロードまたは共有
- `localStorage` に保存してブラウザ上で継続利用可能
- `books.csv`, `shelves.csv`, `config.csv` でデータや設定を簡単に調整

## 使い方

1. `index.html` をブラウザで開く
2. `棚一覧` から棚を選択する
3. `scan.html` でバーコードを読み取る
4. スキャン結果は右側に表示され、最終的に CSV として保存または共有できる

## 主要ファイル

- `index.html` - アプリのトップ画面
- `scan.html` - バーコード読み取り画面
- `shelf.html` - 棚一覧と結果共有画面
- `common.js` - CSV 読み込み・保存・共有やローカルストレージ管理などの共通処理
- `books.csv` - 棚卸し対象の書籍データ
- `shelves.csv` - 棚情報
- `config.csv` - 設定値（例: 廃棄日数や許容期間）
